We added these checks after the results were known, so they supplement the
planned analyses rather than replace them. The

\paragraph{Rates at 0 or 1.}
A bootstrap cannot produce an outcome that never occurred, so when every
answer in a condition receives the same label, its bootstrap interval
collapses to a single point. Exact binomial 95\% intervals avoid this: for
0/20 and 20/20 they are $\USZeroOfTwentyExactCI$ and
$\USTwentyOfTwentyExactCI$. For the differences on the main question below,
Newcombe intervals treat the two conditions as independent samples. A 20/20
result does not mean that the true rate is exactly 1.

\paragraph{Steering intervals that allow for reused seeds.}
These checks concern the earlier 4-bit Llama grid
(Appendix~\ref{app:legacy-steering}), in which each of 50 blocks pairs a
suppressed and an amplified answer. Writing each pair as (suppression,
amplification), with 1 for a positive label, the counts of the four kinds of
pair $(n_{00},n_{01},n_{10},n_{11})$ are
$(\USLiteralCountZeroZero,\USLiteralCountZeroOne,
\USLiteralCountOneZero,\USLiteralCountOneOne)$ at the literal dose and
$(\USCalibratedCountZeroZero,\USCalibratedCountZeroOne,
\USCalibratedCountOneZero,\USCalibratedCountOneOne)$ at the calibrated dose.
The conservative interval treats the 50 pairs as independent and bounds the
two kinds of mismatched pair separately (simultaneous Clopper--Pearson bounds
with a Bonferroni correction).

The grid reused ten random seeds, each in five blocks, so blocks that share a
seed may not be independent. Two intervals allow for this by treating each
seed as a cluster: a bootstrap over seeds, and an approximate $t$ interval
over the ten seed means. With only ten clusters, both are rough. The
Hoeffding bound makes no assumption at all about how blocks that share a seed
depend on each other, which makes it very wide.

The estimates are $\USLiteralEstimate$ and $\USCalibratedEstimate$ under
every method. The planned block analysis excludes an effect of 0.30, and so
do the conservative and seed-cluster intervals; only the Hoeffding bound does
not. The planned verdict therefore stands, but excluding 0.30 depends on how
much independence one is willing to assume. These checks cover only the two
target estimates under the primary judge, not the control panels, the other
judges or the Gemma study.

\paragraph{Fixed versus resampled model panel.}
In the main text, intervals for four-model averages also redraw which models
make up the panel. To measure only the uncertainty within these four models,
we instead keep all four in the panel and resample whole blocks within each
model, still weighting the models equally. On the main question:

Holding the panel fixed narrows every interval, and the average continuation
effect for these four models is then negative under both judges. That
describes this panel, not every model, and neither kind of interval supports
conclusions about language models in general.
