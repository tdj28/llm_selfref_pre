# Pre-SAE target-blind calibration metadata

This Git namespace contains only prospective machine plans and compact,
independently audited receipts for
`consciousness_sae_target_blind_calibration_v2`.

The calibration uses fresh mundane prompts and generic deterministic layer-50
directions. It does not render the paper prompts, load target SAE features, or
pool predecessor rows. Predecessor compact receipts are bound only as disclosed
adaptive-design provenance.

Canonical residual arcs, intervention tensors, transport predictions, logits,
and row-level observations remain under the study's sentinel-bound namespace on
RunPod network volume `bv9gb9j32y`. Git stores hashes and compact audit evidence,
not the raw archive.

Plan directories are immutable evidence:

- `calibration_v2_plan_20260714` is the superseded candidate reviewed by the
  incomplete first Pro call. It was never authorized or executed.
- `calibration_v2_plan_20260714_r2` is reserved for the repaired candidate. It
  must pass independent validation and final review before execution authority
  can be issued.
