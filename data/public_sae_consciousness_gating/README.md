# Earlier Llama Steering Grid

Does target steering alter report labels relative to active matched controls?
This completed NF4 study is the prospective full-grid comparison, distinct
from earlier adaptive pilots and later native-BF16 additive studies. Its
delivery limitations remain part of the interpretation.
