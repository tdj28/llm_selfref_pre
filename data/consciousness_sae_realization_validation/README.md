independently audited receipts for
`consciousness_sae_realization_validation_v1`.

transport measurements, runtime logs, and model artifacts remain on the
sentinel-bound RunPod network volume. They are identified from Git by hashes
and manifests; they are not copied into this repository.

rows, and outcome-derived vectors are prohibited as computational inputs.

reused only after independent byte revalidation.
